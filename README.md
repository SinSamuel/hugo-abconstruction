# ABConstruction Website

A single-page website for **ABConstruction** — commercial framing, painting, decks, and finish carpentry based in Angier, North Carolina.

## Features
- Home with animated SVG wall-framing elevation drawing
- Works gallery (virtual art-gallery aesthetic with per-project modal details)
- Trades / disciplines section
- Hire us contact form

## Tech
Plain HTML + CSS + vanilla JavaScript. No build step needed.

## Deploy
Deployed via Vercel (static site). Any push to `main` triggers a redeploy.
